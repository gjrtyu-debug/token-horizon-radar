# Token Horizon — 암호화폐 코딩 바운티 출품 후보

**현재 상태: 기능 검증을 마친 프로토타입. 정식 대회 등록·제출·상금 수령은 진행되지 않음.**

참가 대상: https://make.fun/bounty/token-radar-01
마감: 2026-12-14 10:00 UTC (한국시간 2026-12-14 19:00)
총 상금: 1,325 USDC (수상 시에만 지급)

## 실행하기 — Windows

1. https://nodejs.org/ 에서 Node.js 24 또는 22.18 이상을 설치합니다.
2. ZIP 파일을 압축 해제합니다.
3. `out/dashboard/index.html`을 크롬 또는 엣지로 열면 가상 데이터로 만든 데모를 볼 수 있습니다. 서버나 계정은 필요 없습니다.
4. 데이터를 다시 계산하려면 해당 폴더에서 PowerShell을 열고 실행합니다.

```powershell
node .\main.ts --input .\sample\synthetic_snapshot.json --output .\out
```

위 명령은 Node.js 22.18 이상 기준입니다. 개발 컨테이너는 22.16.0이어서 `--experimental-strip-types` 플래그를 사용해 검증했습니다.

## 완성한 기능

- 가상의 DefiLlama 형식 데이터 260개 처리
- pre-token 후보 163개, 관찰 목록 40개 전부 포함
- 동종 업계 시가총액/TVL 배수를 통한 가치 시나리오 모델
- 검색 및 chain/category 필터, 정렬, 상세 페이지, 조사 단계 및 CSV 저장
- 오프라인 웹 대시보드, 3가지 실제 브라우저 화면 캡처

**가상 데이터이므로 실제 코인이나 프로젝트를 추천하는 자료가 아닙니다.**

## 정식 제출 전 필수 작업

대회 요구사항은 코드 외에도 공식 키트 내 `vendor/makefun-board.ts` 파일과 `dossier.json`, 공식 입력 데이터에 대한 테스트, 공식 기준 스크린샷, 개발을 수행한 에이전트의 **인증 가능한 원본 세션 기록**을 요구합니다. 현재 격리 환경에서는 공식 키트 다운로드와 실제 ChatGPT 세션 기록의 수상 자격 증명을 만들 수 없으므로, 해당 부분을 수행했다고 주장하지 않습니다.

**중요:** 코드 작성 후 가짜 개발 로그를 생성하거나 다른 AI 에이전트가 만든 코드라고 선언해서는 안 됩니다. 수상 가능성을 위해서는 사용자가 코드 세션이 자동 기록되는 클라이언트(예: Codex CLI, Claude Code 등)에서 새 저장소를 만들어 그곳에서 직접 개발 과정을 기록하며 작성하고, 공식 규정대로 제출해야 합니다. 이 ZIP은 구현 참고·기능 시연 용도로 활용하세요.

공식 참가 준비: GitHub 계정 및 공개 저장소, Solana 호환 지갑(공개 주소만 제출, 개인키 절대 공유하지 않음), Node 22.18+ 혹은 Node 24+, 브라우저, 공식 make.fun 키트.

## 신뢰성 메모

기존 ChatGPT 창에서는 외부 GitHub 저장소 업로드와 지갑 서명을 수행하지 못했습니다. 공식 대회 제출도 이루어지지 않았으며, 당연히 매출과 상금 수령도 0원입니다.
